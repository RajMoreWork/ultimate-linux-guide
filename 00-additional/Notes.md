# waht is the differnace bettwenn systemctl and sudo ?? # 
  sudo → Runs a command with elevated permissions (usually root).
  systemctl → Manages Linux services (start, stop, restart, status).

# what is the difference between update and upgrade??? #
 sudo apt update → Downloads the latest package information. It does not replace or install packages.
 sudo apt upgrade → Installs newer versions of installed packages, replacing the older versions when upgrades are available.
